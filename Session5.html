5. Switch-Case (C++)

        
Alternatif untuk if-else jika kondisinya mengecek satu variabel dengan nilai pasti (angka/char).

        

            Sintaks C++
            

            switch (variabel) {

              case nilai1: // kode; break;

              case nilai2: // kode; break;

              default: // kode lain;

            }
            

        

        
⚠️ Jangan lupa break; agar tidak eksekusi case berikutnya!

Switch vs If-Else: Kapan Pakai?

        

            

                
✅ Pakai Switch-Case

                
Cek satu variabel dengan nilai pasti (1, 2, 3, 'A', 'B').
Contoh: Menu hari, pilihan menu restoran.

            

            

                
✅ Pakai If-Else

                
Cek rentang nilai atau kondisi kompleks (>=, <=, AND, OR).
Contoh: Nilai >= 75, umur > 17 AND punya SIM.

            

        

    


    
    

        
Studi Kasus: Kalkulator Sederhana

2. If operator == '+': hasil = angka1 + angka2
3. Else if operator == '-': hasil = angka1 - angka2
4. ... dst
5. Output hasil

⚠️ Kesalahan Umum Pemula

        

            

                ❌ Lupa Indentasi (Python)
                
if x > 5:
print("besar")

                
Error! Harus ada spasi masuk (Tab/4 spasi).

            

            

                ❌ Lupa Break (Switch C++)
                
case 1: cout<<"A";
case 2: cout<<"B";

                
Tanpa break;, case 2 ikut dieksekusi!

            

            

                ❌ = vs ==
                
if (x = 5) (assignment)

                
Seharusnya == untuk perbandingan!

            

            

                ❌ Nested If Terlalu Dalam
                
If dalam if dalam if dalam if...

                
Sulit dibaca. Pertimbangkan elif atau pecah jadi fungsi.
