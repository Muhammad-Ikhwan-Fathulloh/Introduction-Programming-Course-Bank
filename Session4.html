⚠️ Kesalahan Umum: Input Angka (Python)

        
Lupa konversi input() ke angka akan menyebabkan error saat operasi matematika.

        

            

                ❌ Bug di Python
                
umur = input("Umur: ")
bulan = umur * 12

                
Hasilnya: "202020..." (teks diulang, BUKAN 240)

            

            

                ✅ Solusinya
                
umur = int(input("Umur: "))
bulan = umur * 12

                
Hasilnya: 240 (angka benar)

            

        

        
C++ tidak punya masalah ini karena cin >> umur otomatis konversi ke int.

    


    
    

        
⚠️ Kesalahan Umum: cin Spasi (C++)

        
Di C++, cin >> nama hanya membaca sampai spasi pertama. Nama "Budi Santoso" hanya terbaca "Budi".

        

            

                ❌ Bug di C++
                
string nama;
cin >> nama;
// Input "Budi Santoso"
// nama = "Budi"

            

            

                ✅ Solusinya
                
string nama;
getline(cin, nama);
// Input "Budi Santoso"
// nama = "Budi Santoso"

            

        

        
Python input() tidak punya masalah ini, otomatis baca seluruh baris.

Perbandingan Python vs C++ (I/O)

        

            

                
🐍 Python

                
Output: print()
Input: input() (selalu string)
Format: f"..."
Baris baru: \n otomatis

            

            

                
⚙️ C++

                
Output: cout <<
Input: cin >> (otomatis konversi)
Format: <iomanip>
Baris baru: endl atau \n
