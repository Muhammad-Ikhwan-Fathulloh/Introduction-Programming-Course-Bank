Komputer menyediakan "kotak" di memori RAM. Kita beri nama kotak itu (variabel) dan tentukan jenis isinya (tipe data).

Apa itu Variabel?

Variabel adalah nama yang kita berikan untuk sebuah lokasi di memori komputer, tempat menyimpan data sementara.

📦

Kotak Penyimpanan

Mirip kotak dengan label nama.

🏷️

Nama Jelas

Pakai nama yang deskriptif: umur, bukan x.

🔄

Isi Bisa Berubah

Nilai variabel bisa diubah saat program berjalan.

Aturan Penamaan Variabel

✅ Boleh

nama
umur_25
totalHarga
_secret

❌ Dilarang

2nama (diawali angka)
total harga (ada spasi)
int (kata kunci)
harga-rp (ada tanda minus)

💡 Konvensi: Python pakai snake_case, C++ pakai camelCase atau snake_case.

Tipe Data: Kenapa Harus Beda?

Komputer butuh tahu: data ini angka atau teks? Karena cara memprosesnya beda. Angka bisa dijumlahkan, teks tidak.

🔢

Numerik

int, float, double

📝

Teks

char, string

⚖️

Boolean

True / False

⚠️ Kesalahan Umum: Integer Division

        
Di C++, bagi int dengan int hasilnya selalu int (angka di belakang koma hilang!).

        

            

                ❌ Bug di C++
                
int a = 5; int b = 2;
cout << a / b;

                
Hasilnya: 2 (Bukan 2.5)

            

            

                ✅ Solusinya
                
float a = 5; float b = 2;
cout << a / b;

                
Hasilnya: 2.5

            

        

        
Python tidak punya masalah ini karena 5 / 2 otomatis jadi 2.5.
