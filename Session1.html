📋 Perintah CLI yang Wajib Diketahui

        
Kamu WAJIB menghafal perintah dasar ini untuk navigasi dan mengelola file.

        

            
pwd
Menampilkan folder tempat kamu berada saat ini.

            
ls
Melihat isi dari folder saat ini.

            
cd [nama]
Pindah ke folder lain.

            
mkdir [nama]
Membuat folder baru.

            
touch [nama]
Membuat file kosong baru.

            
rm [nama]
Menghapus file (Permanen!).

            
cat [nama]
Membaca isi file teks.

            
clear
Membersihkan layar terminal.

📋 Perintah Git yang Wajib Diketahui

        
Git dioperasikan 100% via CLI. Ini urutan perintah wajib yang harus dihafal!

        

            
git init
Mengubah folder biasa menjadi folder pelacak Git.

            
git status
Cek perubahan apa yang belum disimpan.

            
git add .
Siapkan SEMUA perubahan untuk disimpan.

            
git commit -m "msg"
Simpan perubahan ke riwayat (Version).

            
git push
Kirim riwayat ke GitHub (Cloud).

            
git pull
Ambil perubahan terbaru dari GitHub.

            
git branch [nama]
Buat cabang/kopi kode agar tidak ganggu utama.

            
git clone [url]
Unduh repo dari GitHub ke laptop.
